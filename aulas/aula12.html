Módulo 12: Instalação do Windows (Formatação)

Com o hardware pronto e a BIOS configurada, agora vamos instalar o cérebro do PC: o Sistema Operacional.

1. Preparação da Mídia (Pendrive Bootável)

Você precisará de um pendrive de no mínimo 8GB em outro computador:

  • Baixe a Ferramenta de Criação de Mídia no site oficial da Microsoft.
  • Siga as etapas para criar um pendrive de instalação para "outro PC".
  • Atenção: Isso apagará todos os arquivos que estiverem no pendrive!

2. O Processo de Instalação

A. O Início

Com o pendrive espetado, ligue o PC. Ele deve iniciar a tela roxa do Windows. Escolha o idioma "Português (Brasil)" e o teclado "ABNT2".

B. Chave de Produto

Quando pedir a chave, se você não tiver uma agora, clique em "Não tenho a chave do produto". Você poderá ativar o Windows depois.

C. Tipo de Instalação

Escolha sempre a opção "Personalizada: Instalar apenas o Windows (avançado)". Isso permite configurar o disco do zero.

D. Partições de Disco

Se o seu SSD for novo, ele aparecerá como "Espaço Não Alocado". Clique em Novo -> Aplicar (o Windows criará partições de sistema automaticamente) e clique em Avançar.

3. Configurações Iniciais

DICA DE PRIVACIDADE: Durante a configuração (Cortana, localização, telemetria), é recomendado desativar as opções de rastreamento de anúncios e envio de dados para deixar o sistema mais leve e privado.

4. Pós-Instalação: Drivers

O Windows está pronto, mas o trabalho não acabou. Você deve:

  1. Rodar o Windows Update para baixar drivers básicos.
  2. Baixar o driver oficial da sua Placa de Vídeo (Nvidia ou AMD).
  3. Acessar o site da fabricante da placa-mãe para baixar os drivers de Áudio e Chipset mais recentes.
